# Glossário Geral Consolidado (todos os manuais)

| Termo | Definição (conforme uso no(s) manual(is)) |
|---|---|
| Manutenção em lote de dados cadastrais | Ferramenta para selecionar múltiplos produtos e alterar seus dados cadastrais de uma vez (status ativo/inativo, movimentação de estoque, etc.). Usada nos manuais 1 e 6. |
| Critérios avançados | Seção de filtros extras nas telas de pesquisa (ex.: Pesquisa de lentes), usada para incluir itens inativos, entre outros critérios. |
| Ativar selecionados / Desativar selecionados | Comandos do menu de contexto que alteram o status ativo/inativo dos itens marcados. |
| Configuração do Financeiro | Tela central de parametrização do módulo Financeiro (abas: Classificações-padrão, Classificações especiais, Juros e CPMF, Carnê, Outros, Contas bancárias). |
| Inventário (Nova) | Ferramenta do módulo Administrador (Estoque) para consulta e ajuste em lote de saldo de estoque. |
| Ajuste de inventário | Nome da tela onde se realiza a pesquisa e o ajuste de saldo de estoque. |
| Mais opções | Janela de ajuste avançado de saldo (atual, mínimo, máximo) na tela de Ajuste de inventário. |
| Condição de pagamento | Conjunto de regras (parcelas, prazos, descontos) que define como um pagamento será recebido/realizado. |
| Baixar | Opção que faz uma parcela ser quitada automaticamente pelo sistema. |
| Data de cadastramento | Campo de filtro (tela de Pesquisa de clientes, aba Avançado → Outros) usado para restringir a busca a um intervalo de datas de cadastro. |
| Movimenta estoque | Campo do cadastro de lentes que determina se o item afeta o controle de estoque. |
| Pesquisar (F3) | Comando/atalho de teclado padrão do sistema para executar uma pesquisa com os critérios definidos. |
