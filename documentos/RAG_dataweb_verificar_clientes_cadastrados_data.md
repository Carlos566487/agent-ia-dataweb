**Conteúdo:**
Módulo Administrador (ou Caixa) — Pesquisa de clientes por data. Para verificar os clientes cadastrados por data, é possível utilizar tanto o **Módulo Administrador** quanto o **Módulo Caixa**.

Passo a passo (exemplo usando o Módulo Administrador):
1. Acesse o **Módulo Administrador** (alternativamente, o Módulo Caixa também permite este procedimento).
2. Acesse **Pesquisas → Clientes...** no menu superior.
3. Na tela **"Pesquisa de clientes"**, selecione a aba **"Avançado"** e, dentro dela, clique na guia **"Outros"**.
4. Nessa guia, utilize o campo **"Data de cadastramento"** — que possui dois campos de data ligados pela palavra **"e"** (intervalo inicial e final) — para definir o período da consulta, e clique em **"Pesquisar (F3)"**.

**Observações:**
- O manual escreve o nome do campo como "Data de cadastro", mas a tela do sistema exibe o rótulo **"Data de cadastramento"**. `[REVISAR: divergência entre o texto do manual ("Data de cadastro") e o rótulo exibido na tela ("Data de cadastramento")]`
- A guia **"Outros"** (dentro de "Avançado") também contém, além do campo de data, um filtro de situação do cliente com as opções **Todos**, **Apenas ativos** e **Apenas inativos**.
- Em caso de dúvidas, o manual orienta entrar em contato com o **suporte Dataweb**.

**Perguntas frequentes relacionadas:**

## Glossário
- **Pesquisa avançada**: modo de busca da tela de Pesquisa de clientes que disponibiliza filtros adicionais, organizados em guias como "Financeiro" e "Outros".
- **Data de cadastramento**: campo de filtro (rotulado assim na tela do sistema) usado para restringir a pesquisa de clientes a um intervalo de datas de cadastro.
